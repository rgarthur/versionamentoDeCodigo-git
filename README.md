# Guilda dos Devs 🐙

Projeto simples (HTML + CSS + JS puro, sem build) feito para aula de Git.

- [index.html](index.html) — estrutura da página
- [style.css](style.css) — visual (fácil de trocar cores)
- [script.js](script.js) — lista de heróis (`herois`) e a lógica de recrutar

## Como abrir

Basta abrir o `index.html` no navegador. Não precisa instalar nada.

## Ideias de exercícios de Git

- Cada aluno adiciona seu próprio herói no array `herois` em [script.js](script.js) e faz um commit.
- Dois alunos adicionando herói na mesma linha do array = conflito de merge para resolver em aula.
- Criar uma branch por feature: nova cor no `style.css`, novo herói no pool de recrutas, nova habilidade em um herói existente.
- Desfazer um commit (`git revert`) que quebrou o jogo (ex: array com vírgula faltando).
